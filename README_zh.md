# Anima 画师串调度混合

Anima 画师串调度混合是一个 Forge Neo 扩展，用来让 Anima 的画师标签更接近 SDXL 画师串的混合方式。

它不会把多个画师名直接交给 Anima 的 LLM 文本编码器一起上下文化理解，而是把每个画师行独立编码，再在采样时把这些画师条件注入并混合到 Anima 的 cross-attention 中。核心思路参考 [An1X3R/Anima-Artist-Mixer](https://github.com/An1X3R/Anima-Artist-Mixer)：拆分画师、独立编码、在 cross-attention 混合，而不是修改文本编码器层。

特别感谢 **An1X3R/Anima-Artist-Mixer** 与 **汐浮尘/utowo** 的原始独立编码和 cross-attention 混合设计。

## 功能

- 每个画师独立一行，可设置画师提示词、权重、介入 block、介入时间、峰值、曲线和阶段预设。
- 画师单元格支持直接写行内倍率，例如 `(wlop:1.2)`、`[wlop:0.8]` 或 `wlop:1.2`；该倍率会与该行 `权重` 相乘。
- 底图与高分辨率修复画师串分离。高分辨率修复默认关闭独立设置，关闭时继承底图。
- 设置变化时会自动保存当前 UI 状态，刷新 UI 或重启 Forge 后会直接恢复上次设置。
- 模板保存、应用、重命名和删除。应用模板后所有参数仍可继续手动修改，也可跨会话复用。
- 支持一键全部恢复内置默认设置，不会删除已保存模板。
- 可选择在高分辨率修复阶段不启用画师串混合，只让底图阶段使用混合。
- 模板使用稳定内部值保存，可在中文/英文 UI 之间互相应用。
- 优化预设、组合模式、融合模式、曲线、阶段、模板应用目标等选项会随界面语言显示。
- 性能、平衡、质量三个优化预设，默认平衡。
- 面板顶部支持中英文 UI 切换，只会局部刷新当前插件面板。
- 文本编码缓存，重复画师和提示词时减少编码开销。
- 默认使用更接近参考项目的 `输出平均 + 插值融合`，同时保留更稳的 `保真增量`，方便在需要保守混合时切换。

## 行控制

建议每行只放一个画师提示词。这样每个画师都能独立控制权重、层数、时间、曲线和阶段。为了迁移旧画师串，逗号分隔仍然可用，但每行一个画师更容易得到可预测的调度效果。

`阶段 + Shift + 自动Shift` 会用类似 Anima LoRA Stage Scheduler 的方式重写该行时间窗口：构图偏早，人物居中，画风偏晚。选择自定义之外的阶段时，开始、结束和峰值会立刻刷新。之后如果想手动微调，再关闭自动Shift即可。

## 设置与模板

修改任意主要控件时，插件会把当前状态写入本地 `artist_mixer_current_settings.json`。该文件已加入 git 忽略，只用于刷新 UI 或重启后恢复你的上次面板状态。

点击 `全部恢复默认` 会清除当前设置文件并恢复插件内置默认值。该操作不会删除模板文件。

高分辨率修复页签中有 `高分辨率修复不启用画师串混合`。开启后，插件会在 Hires. fix 阶段开始前取消混合 patch，让高分修复保持原始生成逻辑。

## 推荐默认值

- 优化预设：`平衡`
- 组合模式：`输出平均`
- 融合模式：`插值融合`
- 全局画师强度：`0.70`
- 默认层数：平衡和质量 `0-27`，性能 `10-18`。
- 如果插值融合对某个提示词太强，再切到 `保真增量`。

## 注意

Anima 使用非线性的 LLM 文本编码器，因此无法做到 SDXL 画师混合那种近似无损。这个插件的目标是降低画师标签之间的上下文干扰，让风格混合更可控。

插件只在采样期间包装 Anima cross-attention，生成结束后会还原原始 forward；不会修改文本编码器层或模型文件。
